# Ayushi's Fairytale

Here's a detailed prompt you can give to Gemini Canvas, Google AI Studio, Claude Code, Lovable, Bolt, v0, or any AI website builder to create a premium, cinematic Girlfriend's Day website.

Prompt

Create an incredibly beautiful, premium-quality, single-page romantic website for International Girlfriend's Day dedicated to Ayushi.

The website should feel like a Disney fairytale mixed with Apple's elegant design language.

The design must NOT look like a template.

It should feel handcrafted, emotional, magical, cinematic, and full of delightful interactions.

Overall Emotion

The experience should make her feel as though she has stepped into a magical love story created just for her. Every animation should be smooth, elegant, and meaningful—not flashy. Focus on warmth, intimacy, surprise, and delight, with subtle details that reward interaction and create lasting memories. The final result should feel polished enough to rival a premium interactive microsite rather than a standard greeting card.
